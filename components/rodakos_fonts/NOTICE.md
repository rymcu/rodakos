# RodakOS UI fonts

This local component contains the generated LVGL font sources and the icon map required by
the RodakOS UI. It is intentionally a small, RodakOS-owned subset rather than a dependency on an
assistant or device-firmware project.

The CJK subset `font_puhui_16_4.c` was imported from the `78/xiaozhi-fonts` 1.6.0 component.
The upstream component metadata declares MIT licensing.

The UI icons (`rodakos_icons_20_4.c`, `rodakos_icons_30_4.c`, `include/rodakos_icons.h`) are
generated by `tools/generate_icon_fonts.py` from `icons.json`. The glyphs come from Ionicons
