## PhoneShell 全局叠层机制

`PhoneShell` 在 `lv_layer_top()` 上维护三个跨应用常驻体验，打开或关闭它们**不会替换或销毁当前前台应用**：

- **锁屏（Lock Screen）**：展示时钟、网络状态与消息未读计数，通过滑动解锁（在启用 PIN/Flash 加密前定位为隐私遮挡）。
- **控制中心（Control Center）**：提供 Wi-Fi 状态、背光滑块、快捷跳转设置与立即锁屏入口，默认通过 **IO10 物理键单击** 或顶栏手势呼出。
- **底部语音字幕栏（Voice Bar）**：展示 `turn.progress` 与逐帧同步的 `output.caption`，当锁屏/控制中心模态窗、软键盘、Toast 或 WebRTC 屏幕共享激活时自动礼让或隐藏。

## 编写新内置应用的规范

1. 在 `main/apps/<app>/` 下实现 `PhoneApp` 子类（`OnCreate` / `OnDestroy` / `OnResume` / `OnPause`）。
2. 所有 LVGL API 调用统一使用 `PhoneUiLock lock(ui);` 保护，样式优先复用 `rodakos_theme.h`、`rodakos_layout.h` 与 `phone_components.h`。
3. 通过 `Register<App>App(registry)` 在 `main/apps/built_in_apps.cc` 中静态注册，确保 ID 与别名全局不冲突（注册表冲突会阻止 Home 创建）。
4. 将新增源文件加入 `main/CMakeLists.txt`，并尽量补充独立 WSL 主机端 UI 测试。
