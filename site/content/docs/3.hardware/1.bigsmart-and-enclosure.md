## RYMCU BigSmart 参考硬件规格

`components/rodakos_hal_boards/boards/rymcu/rymcu_bigsmart/` 保存着当前唯一官方支持板卡的声明式配置：

| 模块 | 芯片 / 规格 | 接口 / 说明 |
| --- | --- | --- |
| **主控与存储** | ESP32-S3-WROOM-1-N16R8 | 16 MB Flash，8 MB PSRAM，2.4 GHz Wi-Fi |
| **显示与触控** | 320×240 ST7789 LCD + GT911 电容触控 | 80 MHz SPI 显示 + 缓存轮询 I2C 触控 + LEDC 背光 |
| **音频系统** | ES8311 DAC + ES7210 四通道 TDM ADC | 共享 I2S0 四槽 16-bit 帧，双麦拾音 + 腔体扬声器 |
| **摄像头** | GC0308 DVP 摄像头 | 8-bit DVP + PCA9557 电源使能，按需开启 |
| **传感器与外设** | QMI8658 六轴 IMU、PCA9557 IO 扩展、WS2812 RGB | 后台低优先级 I2C 采样 + RMT 单灯控制 |
| **按键与扩展** | IO0 BOOT + IO10 侧键、MicroSD（1-bit SDMMC）、USB-C、电池接口 | IO10 支持单击/双击/长按自定义绑定 |

社区若要移植其他 ESP32-S3 开发板，应在 `components/rodakos_hal_boards/boards/<vendor>/<board>/` 下新增板级 YAML 与 `setup_device.c`，通过显式构建选型并跑通硬件验收，而不是在 `main/` 下重起手写板级代码。

## 开源全参数化 3D 打印外壳（`BigSmart-Open/enclosure`）

::note
**仓库职责分工**：BigSmart 主板与专属外壳的 CAD 源码（`build123d` 参数化建模脚本、STEP/STL 与参考硬件模型）统一归口在硬件仓库 [rymcu/BigSmart-Open/tree/main/enclosure](https://github.com/rymcu/BigSmart-Open/tree/main/enclosure)；`rodakos` 固件仓库官网仅保留用于网页 3D 交互展示的轻量化 `rodakos-enclosure.glb` 网格。
::

该参数化外壳工程基于 Python **build123d** 构建，包含完整主机（`106.0 × 86.0 × 33.2 mm`）与可分离 **15° 桌面底座**：

- **声学与结构优化**：双麦气密导声台（贴单层 1.2–1.5 mm 闭孔泡棉即可密封）、3525 腔体喇叭 ~80% 高开孔护筋大窗与 9.6 mm 独立隔音围墙、0.60 mm 隐形柔光 RGB 透光仓、齐平 GC0308 镜头孔。
- **零干涉校验**：内置 `verify.py` 对真实主控板、屏幕与按键麦板 STEP 模型做全量 B-rep 零干涉检查和螺丝啮合审计。
- **两款常见螺丝搞定全机**：全机 19 颗螺丝统一为 **M2×5**（11 颗）与 **M3×6**（8 颗）盘头自攻螺丝。

### 本地重新生成 STL / STEP 与干涉验证

克隆 [rymcu/BigSmart-Open](https://github.com/rymcu/BigSmart-Open) 后，在 `enclosure/` 目录下运行：

```powershell [BigSmart-Open / enclosure]
# 完整构建 + 含主控板全量 B-rep 干涉检查 + 导出 STL/STEP 与渲染图
uv run --python 3.12 --with build123d --with matplotlib --with numpy python enclosure/build.py
```

### FDM 打印建议

- 材料：PLA 或 PETG，0.20 mm 层高，3–4 层壁厚，20%–30% 填充。
- 6 个打印件（`front_shell`、`mid_frame`、`rear_shell`、`camera_clamp`、`rear_retainer`、`desktop_cradle`）的 `out/stl/*.stl` 均已按几乎免支撑的最佳朝向摆放。
