无论你是希望自建兼容 Rodak 协议的设备、编写固件模拟器，还是深入排查配对、命令重放与实时语音打断问题，RodakOS 都提供了完整的机器可读契约（[`contracts/`](https://github.com/rymcu/rodakos/tree/main/contracts)）、在线协议开发者手册与浏览器交互实验室。

## 三条通道，一个令牌

| 通道 | 核心职责 | 连接时机 | 鉴权方式 |
| :--- | :--- | :--- | :--- |
| **HTTP(S)** | 身份、配对/SRP6a 首次建信、600s 令牌刷新、OTA 下载、消息中心同步、解绑 | 按需请求 | Bearer HS256 JWT（钉扎 TLS） |
| **MQTT(S)** | 遥测、设备影子、命令与 64 条防重放回执、音量/灯光效果、OTA 通知、WebRTC 信令、`voice.announce`、`inbox/changed` | 绑定后通常保持连接 | JWT 作密码 + 连接纪元隔离 |
| **WSS** | `rodak-realtime-voice/v1` 实时语音会话、RAV1 二进制音频帧、`turn.progress` 与 `output.caption` | 仅在本地唤醒或主动播报时打开 | Bearer HS256 JWT（四道消息门控） |
