RodakOS 严格锁定 **ESP-IDF 6.0.2** 与其 `tools/tools.json` 指定的 Xtensa GCC 工具链。项目脚本会自动拒绝其他 IDF 版本，且**无需修改全局 PowerShell Profile**。

## 1. 激活项目本地 ESP-IDF 6.0.2 环境

在仓库根目录执行（每个 PowerShell 会话执行一次）：

```powershell
. .\activate_idf.ps1 -Version v6.0.2
idf.py --version
```

`activate_idf.ps1` 会自动扫描 `C:\esp\<vX.Y.Z>\esp-idf\`、读取 `C:\Espressif\tools\eim_idf.json` 或回退到 `$env:IDF_PATH`。

## 2. 首次构建与日常增量编译

```powershell
# 首次构建、修改板级 YAML 或删除生成目录后：
.\build_rodakos.ps1

# 日常修改应用或服务代码后的增量编译（仅生成 ota_0 主应用）：
idf.py build
```

`components/gen_bmgr_codes/` 由 `generate_board_config.ps1` 自动生成并已加入 `.gitignore`，切勿手工修改其中的生成路径。

## 3. 打包 Recovery + 签名 OTA 与安全刷机

> **严禁在 Recovery 分区布局上直接运行根目录 `idf.py flash` 或 `idf.py app-flash`**——它们会尝试把主程序写入仅 2.5 MiB 的 `factory`（Recovery）分区。

### 打包主应用 + 不可变 Recovery

```powershell
# 开发密钥本机签名打包
.\build_ota_bundle.ps1 `
  -SigningKeyPath C:\secure\ota-private.pem `
  -VerificationKeyPath C:\secure\ota-public.pem `
  -SigningTaskNo <rodak-task> -SigningVersion 0.1.6

# 生产模式：私钥保持离线，构建机仅传入公钥
.\build_ota_bundle.ps1 `
  -VerificationKeyPath C:\secure\ota-public.pem `
  -SigningTaskNo <rodak-task> -SigningVersion 0.1.6 -OfflineSigning
```

### 刷入与验证开发板

```powershell
# 首次迁移到 Recovery 布局（会清空 NVS 与全部设备状态）：
.\flash_and_test.ps1 -Port COM3 -Erase -NoMonitor

# 已在 Recovery 布局上的日常刷新（先只读校验分区表与 Recovery 哈希，再仅写 otadata 与 ota_0）：
.\flash_and_test.ps1 -Port COM3 -VerifyOnly
.\flash_and_test.ps1 -Port COM3 -NoMonitor
```

健康首启日志应依次出现以下关键标记：

```text

Board manager initialized
Touch input registered with cached polling
LVGL port initialized
BacklightAdapter: Backlight adapter initialized
PhoneSystem: Starting Phone OS
HomeApp: Phone desktop ready with N apps
OtaUpdate: Local boot confirmation complete
RodakOS: RodakOS started successfully
```

## 4. 运行 64 套 WSL / Linux 主机端测试

无需连接 ESP32-S3 开发板，即可在 WSL Debian 或 Linux 下编译真实 LVGL 9.3 与核心服务源码：

```bash
# 运行单个主机测试套件（例如 app_model 或 home_ui）
cmake -S /mnt/d/workspace/rodakos/tests/app_model \
      -B ~/.cache/rodakos-app-model -G Ninja -DCMAKE_BUILD_TYPE=Debug
cmake --build ~/.cache/rodakos-app-model
ctest --test-dir ~/.cache/rodakos-app-model --output-on-failure

# 运行完整 ASan/UBSan 发布回归（需指向已审阅的 ESP-IDF 6.0.2 源码树）
export RODAKOS_IDF_PATH=/path/to/esp-idf-v6.0.2
bash tools/run_release_host_checks.sh "$HOME/.cache/rodakos-release"
```
