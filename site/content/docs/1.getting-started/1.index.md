**RodakOS**（当前版本 `v0.1.6`）是面向 **ESP32-S3（RYMCU BigSmart）** 的开源微型 “Phone OS” 固件。它基于 **ESP-IDF 6.0.2**、**LVGL 9.3** 与 **Espressif Board Manager** 构建，在 320×240 电容触控屏上提供 16 款原生应用、本地 MultiNet 唤醒、流式实时语音字幕与安全 OTA。

## 离线独立使用 vs. 协同 Rodak 服务端

| 场景 | 可用能力 | 网络要求 |
| --- | --- | --- |
| **独立掌上终端（离线）** | Home 多页桌面与文件夹、Settings、4 套本地配色主题、Clock、1900–2100 离线农历日历、Photos、MP3/WAV Music、20 柱电平表 Recorder、GC0308 Camera 拍照、Files 文件浏览、QMI8658 气泡水平仪、早启动 USB U 盘模式 | 无需网络（SD 媒体类应用需插入 FAT 格式 MicroSD 卡） |
| **局域网工具** | Wake-on-LAN（持久化最多 8 台主机）、SNTP 网络对时、内置 Web 文件服务 | 仅需 2.4 GHz 局域网 Wi-Fi |
| **完整语音与全屋协同** | 离线唤醒后开启 `rodak-realtime-voice/v1` 实时语音对话、Shell 底部逐帧回复字幕、Messages 消息中心与待办推迟/完成、Smart MQTT 灯控联动、WebRTC 摄像头/屏幕远程同传、外观工坊签名发布与 SD Recovery OTA | 需在局域网电脑或 NAS 上运行 [Rodak](https://github.com/rymcu/rodak-releases) |

## 首次配网的两种方式

### 方式一：USB 一键可信配网（推荐初次刷机）

1. 用数据线将 BigSmart 连接到运行 **Rodak 桌面端** 的电脑。
2. 在 Rodak 左侧展开 **高级与开发者工具 → 串口**，完成固件烧录。
3. 输入家庭 2.4 GHz Wi-Fi 凭证并勾选信任本机服务端，Rodak 会通过串口写入固定的 `.local` 服务端证书指纹与配对信息。
4. 设备重启联网后，会自动注册 `rodakos-xxxxxx.local` mDNS 主机名，并通过钉扎 TLS（HTTPS / MQTTS / WSS）安全上线。

### 方式二：免 USB 的局域网 6 位验证码（SRP6a）

若设备已经刷好 RodakOS 且接入同一局域网 Wi-Fi，无需再插 USB 线：

1. 在设备 **Settings → 连接服务** 发起局域网首次配对，屏幕会显示一个 6 位一次性验证码。
2. 在 Rodak 服务端确认发现的设备并输入该 6 位验证码。
3. 双方通过 **SRP6a** 完成零明文密钥交换，并将服务端信任根锁定到设备 NVS，后续 DNS-SD 候选路由均须通过 TLS 验证才会升级切换。

## 当前发布状态说明（NO_GO）

RodakOS 坚持证据分级与工程透明。尽管核心特性均已通过 53 套 ASan/UBSan C++ 发布回归及 Python 契约校验，并在各自带日期的候选构建上取得 BigSmart 真机记录（当前源码版本 `0.1.6`），**生产发布目前仍保持 `NO_GO`**，等待以下 3 项物理门禁记录完整实测证据：

- [#30](https://github.com/rymcu/rodakos/issues/30)：生产离线签名根部署与正式签名 Rodak OTA
- [#29](https://github.com/rymcu/rodakos/issues/29)：下载、FAT 刷盘/重命名、Flash 与 NVS 写入期间的真实物理断电矩阵
- [#28](https://github.com/rymcu/rodakos/issues/28)：普通正式构建包的 8 小时连续资格烤机
